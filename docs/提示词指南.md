# Z-Image 提示词指南

Z-Image-Turbo 的文本编码器是 **Qwen3-4B**（`CLIPLoader` 的 `type` 选 `lumina2`），
**中文提示词原生可用**——这一点和 MiniMax-H3-Image（必须全英文）完全不同，
写中文省事得多，也更符合中文语料的描述习惯。

---

## 1. 提示词结构

一段话，按这个顺序写最稳：

```
[画面类型/风格] + [主体] + [动作/姿态] + [场景/环境] + [光线] + [材质/质感] + [画质修饰]
```

对比一下两种写法：

| 写法 | 例子 | 效果 |
|---|---|---|
| 标签串 | `cat, window, sunlight, 4k, masterpiece` | 元素都在，但没构图，像凑的 |
| 成句 | `一只橘猫坐在洒满午后阳光的木质窗台上，脖子上系着一条淡蓝色条纹围巾，窗外是虚化的绿植与暖色天空，柔和的自然光，细腻的毛发质感，温暖的色调，插画风格，高细节` | 有主体、有景深、有光影，构图成立 |

**关键：把"画面类型"写出来。** Z-Image 对风格词很敏感：

```
插画风格 / 赛璐璐动画风格 / 水彩 / 厚涂 / 油画 / 胶片摄影 / 35mm 摄影 / 写实照片 / 3D 渲染
```

不写风格词时，模型会在写实照片和插画之间摇摆。

## 3. 负面提示词的真相

**cfg = 1.0 时，负面提示词不参与计算**（Turbo 是 guidance-distilled 模型）。
本机历史出图里那串负面词是特定用途留下的，不能照抄：

```
blurry, low quality, deformed, bad anatomy, extra limbs, floating limbs,
wrong position, censored, clothes, text, watermark
```

注意里面那个 **`clothes`**——那是历史负面词里的遗留项，
**照抄会让所有图都不穿衣服**。

想让画面干净，正确的做法是**在正面提示词里写否定表达**，例如：

```
……画面干净，不要任何文字、水印或签名
```

而不是往负面框里塞词。

---

## 4. 文字渲染

Z-Image **不能可靠地渲染文字**。招牌、包装、书页上的字基本都是乱码形状。
需要文字就后期加，不要指望模型写对。

## 5. 参数选择速查

| 场景 | sampler | scheduler | steps | cfg | 备注 |
|---|---|---|---|---|---|
| 文生图（默认） | `euler` | `simple` | 9 | 1.0 | 本机 29 张出图都用这套 |
| AuraFlow 变体 | `res_multistep` | `simple` | 8 | 1.0 | 加 `ModelSamplingAuraFlow(shift 3.0)` |
| ControlNet 结构控制 | `res_multistep` | `simple` | 8 | 1.0 | 加 `ModelPatchLoader` + `ZImageFunControlnet` |
| 遮罩局部重绘 | `dpmpp_2m_sde_heun_gpu` | `sgm_uniform` | 9 | 1.0 | 同上，额外接 `inpaint_image` + `mask` |

**cfg 永远 1.0**，别的都会崩。

> 采样器名没有 `dpmpp_2p_sde_heun` 这个东西，下拉里只有 `dpmpp_2m_sde_heun` 和
> `dpmpp_2m_sde_heun_gpu`。

画布：本机 1024×1024；显存够的话可以上 1536×1536 或 2048×2048。

## 5.5 局部重绘的提示词怎么写

遮罩重绘时，模型能看到的只有三样东西：**你的提示词**、**遮罩区外的原图像素**、
**遮罩区被清空后的灰底**。所以：

1. **别只写"把这里改成红色"。** 模型不知道遮罩外是什么，
   提示词要写成**改完之后的完整画面**，主体、场景、光线、风格全写上，
   和普通文生图的写法一模一样：

   ```
   一只橘猫坐在洒满午后阳光的木质窗台上，脖子上系着一条红色的缎面蝴蝶结，
   窗外是虚化的绿植与暖色天空，室内静谧，柔和的自然光，细腻的毛发质感，
   温暖的色调，插画风格，高细节
   ```

   而不是：

   ```
   红色的蝴蝶结            # 遮罩外整张图会被重画成乱码
   ```

2. **风格词要跟原图一致**，否则遮罩内外会出现明显的画风断层。

3. **ControlNet 结构控制时**，提示词写"画什么"，canny 边缘图写"画在哪"。
   想换主体就换主体（猫→柴犬），构图和姿势由边缘图保住。

4. **想换姿势/构图就别用 canny 局部重绘**，
   边缘图会把旧姿势一起锁死。

5. **Z-Image-Turbo 做不到"整张照着参考图重画"**。
   ComfyUI 0.45.0 里能喂参考图潜变量的只有 Flux Kontext 系和 Z-Image-**Omni**，
   Turbo 没有这个通道。可行的只有"结构控制"和"遮罩局部重绘"两条路。

## 6. 范例

### 6.1 温暖日常（插画）

```
一只橘猫坐在洒满午后阳光的木质窗台上，脖子上系着一条淡蓝色条纹围巾，
窗外是虚化的绿植与暖色天空，室内静谧，柔和的自然光，细腻的毛发质感，
温暖的色调，插画风格，高细节
```

### 6.2 赛博夜景（写实）

```
雨夜的霓虹街道，湿漉漉的柏油路面映出粉紫色与青蓝色的招牌倒影，
一个撑透明伞的女孩背影走在画面右侧，路面积水溅起细小水花，
冷调环境光中只有一盏暖黄路灯，画面边缘有轻微雾气，
胶片摄影质感，35mm 镜头，浅景深，高动态范围
```

### 6.3 静物（油画）

```
一张老木桌上摆着一只粗陶杯、一本摊开的旧书和一小枝干花，
窗外是秋天的灰绿色庭院，柔和的自然侧光从左侧进入，
陶杯上有粗糙的釉面质感，书页边缘泛黄卷曲，
古典油画风格，细腻的笔触，暖褐色调
```

### 6.4 想要"无文字"的写法

```
……画面干净整洁，不要任何文字、字母、水印或签名
```

### 6.5 反例

```
猫, 室内, 阳光, 高清, 杰作, 8k, masterpiece, best quality
```

标签串没有构图、没有光线逻辑，元素会平铺、互相不搭。
**写成成句。**

---

## 7. 一句话总结

> Z-Image 吃"**一段有主语、有场景、有光线的成句**"，中文即可；
> 先写画面类型，再写主体，最后补光线和质感；cfg 锁 1.0，负面框没用。
