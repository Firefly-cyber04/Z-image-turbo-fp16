## 2. 启动参数

```bat
python ComfyUI\main.py --windows-standalone-build --reserve-vram 1.0 --lowvram --fast-disk --mmap-torch-files --preview-method none --port 8188
```

| 参数 | 作用 |
|---|---|
| `--lowvram` + `--reserve-vram 1.0` | 12.3GB 的 DiT 塞进 8GB 显存，权重分页到内存 |
| `--fast-disk` + `--mmap-torch-files` | 8GB 的文本编码器靠 NVMe 分页托底 |
| `--preview-method none` | 省掉预览图的额外采样开销 |

## 3. 节点与参数（实测，非官方模板抄录）

本机 39 张出图的 PNG 元数据里记录的参数组合：

### 文生图（29 张）

```
UNETLoader(z_image_turbo_bf16.safetensors, weight_dtype=default)

```

### AuraFlow 文生图（2 张）

```
+ ModelSamplingAuraFlow(model=UNET, shift=3.0, sampling=flow)
KSampler: res_multistep / simple / 8 steps / cfg 1.0
```

### ControlNet 结构控制（本轮实跑验证）

照 ComfyUI 0.45.0 官方模板 `image_z_image_turbo_fun_union_controlnet.json` 搭：

```
UNETLoader(z_image_turbo_bf16.safetensors, weight_dtype=default)
CLIPLoader(qwen_3_4b.safetensors, type=lumina2, device=default)
VAELoader(ae.safetensors)
CLIPTextEncode(prompt) ─ positive
ConditioningZeroOut(positive) ─ negative
LoadImage ─ Canny(0.25, 0.6) ─ image ─┐
EmptySD3LatentImage(1024, 1024) ───────┼─ KSampler(latent_image)
ModelPatchLoader(Z-Image-Turbo-Fun-Controlnet-Union-2.1-8steps) ─ model_patch ─┤
UNETLoader ─────────────────────────── model ─┐
VAELoader ─────────────────────────────────── vae ─┴─ ZImageFunControlnet(strength 1.0)
                                                     ─ ModelSamplingAuraFlow(shift 3.0) ─ KSampler(model)

KSampler: res_multistep / simple / 8 steps / cfg 1.0 / denoise 1.0
```

> **不要接 `VAEEncode` + `SetLatentNoiseMask`**——官方模板也没有。latent 用 `EmptySD3LatentImage`，
> 输入图只作为边缘图条件。
>
> **canny 阈值**：官方是 `0.1 / 0.32`，在毛发主体上会把每根毛当边缘、模型再画成黑色条纹。
> 毛茸茸主体改用 `0.25 / 0.6`。

### 遮罩局部重绘（本轮实跑验证）

```
LoadImage ─┬─ image ───────────────────────────────── inpaint_image ─┐
           ├─ mask ─┬─ VAEEncode(image) ─ SetLatentNoiseMask ─ latent ─ KSampler
           │        └────────────────────────────────── mask ─────────┤
UNETLoader ───────────────────────────────────────── model ─────────┤
ModelPatchLoader ─────────────────────────────────── model_patch ───┤
VAELoader ─────────────────────────────────────────── vae ───────────┴─ ZImageFunControlnet(strength 1.0)
                                                                          ─ ModelSamplingAuraFlow(shift 3.0) ─ KSampler

KSampler: dpmpp_2m_sde_heun_gpu / sgm_uniform / 9 steps / cfg 1.0 / denoise 1.0
```

遮罩来自输入 PNG 的 **alpha 通道**：`LoadImage` 输出 `mask = 1 - alpha`，alpha=0 处 mask=1 = 重绘区。

**cfg 一律 1.0**：Turbo 是 guidance-distilled 模型，cfg>1 会崩，负面提示词在 cfg=1 时不参与计算。

> `ModelPatchLoader` 是**模型补丁**（挂在 DiT 上），不是 `ControlNetLoader`，
> 且必须排在 `UNETLoader` 之后、`KSampler` 之前。
>
> 应用补丁的节点用 **`ZImageFunControlnet`**，它输出 MODEL（不是 CONDITIONING），
> 所以要排在 `ModelSamplingAuraFlow` 前面。

## 4. 画布与分辨率

本机用 **1024×1024**。Z-Image-Turbo 原生支持到 2048²；
8GB 显存 + 16GB 内存下 1024² 最稳，再大直接 OOM。

## 5. 踩过的坑

- **遮罩全 0 = 输出等于输入原图**（本轮最坑）：`LoadImage` 的 `mask = 1 - alpha`，
  **JPEG 没有 alpha 通道 → mask 全 0**；`SetLatentNoiseMask` 让采样器每一步都把原 latent
  混合回去（`comfy/samplers.py:634-642`），于是输出是原图的逐像素复制，
  看起来像"ControlNet 完全没生效"。排查第一步：确认 mask 不是全 0。
- **API 提示词里连线 id 必须是字符串**：写成 `["12", 0]` 而不是 `[12, 0]`。
  否则 ComfyUI 在 `execution.py:951` 抛 `KeyError`，而且报的是**另一个节点**的错，极难定位。
- **采样器名写错**：没有 `dpmpp_2p_sde_heun`，实际是 `dpmpp_2m_sde_heun` /
  `dpmpp_2m_sde_heun_gpu`。
- **canny 阈值别照抄官方的 0.1/0.32**：毛发主体上会画出黑色条纹，改用 `0.25/0.6`。
- **PowerShell 5.1 读中文 JSON 会花**：脚本里必须
  `[System.IO.File]::ReadAllText($f, [Text.Encoding]::UTF8)`，
  不能用 `Get-Content -Raw`（默认 ANSI 码页），否则中文提示词变乱码甚至让 JSON 解析失败。
- **`Invoke-RestMethod` 传中文 body 会变成 `??????`**：要自己
  `[Text.Encoding]::UTF8.GetBytes($body)` + `ContentType 'application/json; charset=utf-8'`。
- **ControlNet 用错节点**：必须 `ModelPatchLoader` + `ZImageFunControlnet`。
- **cfg 别乱调**：蒸馏模型，cfg>1 直接崩。
- **8GB 显存跑 bf16 很吃力**：DiT 12.3GB + 编码器 8GB，内存峰值贴 16GB 上限。
  换 int8 档是最划算的一步。
- **权重下载别走 hf-mirror**：只有 3 MB/s，ModelScope 直链 9–11 MB/s。
